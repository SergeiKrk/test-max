# Проверка тестового задания

Дата: 26.09.2026.

## Соответствие ТЗ

| Требование | Реализация |
| --- | --- |
| React, MAX, GREEN-API | React 19; прямые запросы к GREEN-API MAX из браузера |
| Ввод idInstance и apiTokenInstance | Проверка авторизации через GetStateInstance; данные только в памяти |
| Создать чат по номеру | CheckAccount возвращает chatId, который используется в переписке |
| Отправить текст | SendMessage; статус принятия API не выдаётся за доставку |
| Получить ответ в том же чате | Последовательный ReceiveNotification и DeleteNotification после обработки |
| Внешний вид по прототипу MAX | Адаптивный список чатов, заголовок, фон, пузыри и композер; сверка с авторизованным референсом |
| Минимальный набор функций | Только текст, создание/выбор чата, отправка, получение и выход; без звонков, файлов и голосовых |

Экран подключения дополнительно оформлен анимацией. Основной сценарий доступен сразу; reduced motion отключает декоративное движение.

## Проверки и границы подтверждения

- Пройдены 73 модульных теста и 4 Playwright-сценария на вымышленных данных, ESLint и production build с TypeScript.
- Проверены подключение, отказ/повтор, поля и скрытие токена, отправка/получение/подтверждение, выход, адаптивность и reduced motion.
- Пользователь ранее подтвердил реальный обмен через приложение. Итоговый повтор после последних изменений и обмен с опубликованного домена в рамках этой проверки не выполнялись.
- Скриншоты в `screenshots/` сделаны на моках API и не доказывают доставку на реальном сервисе.
